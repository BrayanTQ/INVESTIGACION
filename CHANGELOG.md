# Registro de cambios

## 0.1.1 - Interfaz y colaboración en español

- Plantillas de incidencias y Pull Request en español.
- Mensajes, ayudas y errores de la CLI en español.
- Comandos principales en español con alias en inglés por compatibilidad.
- Guía de roles y accesos para GitHub.
- Nombres visibles de GitHub Actions en español.
- Documentación de seguridad y contribución en español.

## 0.1.0 - Primera versión

- Perfil de búsqueda exclusivo Sentinel-1: `IW`, `GRD_HD`, `VV+VH`.
- Definición de AOI mediante punto+radio, BBOX y GeoJSON.
- Generación de manifiestos de búsqueda.
- Descarga de productos seleccionados desde un manifiesto.
- Autenticación NASA Earthdata mediante token, credenciales o netrc.
- Pruebas unitarias y flujo de integración continua.
